# AirSIM Apps v0.9.8.10 — 短信去重、换卡号码刷新与 VoWLAN/VoBLE 恢复

日期：2026-10-24（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.10 (115)`，iOS／Watch／Live Activity `0.9.8 (139)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM、双 SIM、锁屏或长时后台场景均已验收。

## 更新内容

- **短信通知去重**：APNs 与 VoWLAN/HTTP 本地通知共用 `agentID + delivery_id` 通知账本；联系人姓名只影响标题。Push 先到、本地先到、App 重启和后台锁屏均按同一身份判断，避免同一条短信出现“号码”和“联系人姓名”两条通知。
- **通知负责人**：Cloud/APNs 可用时由 APNs 负责提醒，本地同步只更新会话；本地/BLE 模式由本地通知负责。本地 identifier 改为稳定派生值，不再使用 Swift `hashValue`。
- **Relay 短信身份**：APNs payload 增加 `agent_id`；短信去重键和 `collapseID` 按 `device_id + agent_id + delivery_id` 隔离，避免不同 Agent 的相同内容互相覆盖。
- **换卡号码刷新**：iPhone 不再在新 SIM 号码为空时回退显示旧号码；Android 增加 subscription-scoped 号码读取，Relay 心跳允许空值清除云端旧号码。
- **VoBLE 断开诊断**：增加 `local_cancel`、`is_reconnecting`、脱敏错误域/错误码、连接和认证失败事件；补强 call ownership，空 callID 或 generation 0 不再被当成待接管通话。
- **VoBLE 通话期停扫**：仅在 VoBLE 通话期间暂停共享 BLE 扫描，通话结束恢复；空闲已认证链路仍可发现和切换其他 Agent，避免拨号期间扫描与 GATT 竞争。
- **VoWLAN Wi-Fi 漫游恢复**：相同 `satisfied` 但 gateway/interface 改变时重新发现；未验证的旧手动地址不再覆盖同一 Agent 的新 Bonjour 地址；切换备用地址时先更新 preferred endpoint，保留已验证/通话中路由。
- **VoWLAN 健康与配对**：前台恢复不再反复重启 Bonjour；已验证的手动配对不会因 Tailscale 健康探测超时被丢弃；配对记录按 Agent 保留多个地址。
- **Telecom 诊断**：Android 记录原始 Telecom 状态、接通时间和 `DisconnectCause`，用于区分拨号中止、运营商断开和音频未启动。
- **兼容性修复**：VoBLE 广播适配 Android 机型名；旧 AVF 无接口时不再反复重启 PCM；VoWLAN 配对存储正确处理受检 JSON 异常。
- **文档**：补充 Shizuku 13.6.0 在 HyperOS 3 上的 PCM 启动回归说明和 13.5.4 规避建议。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.10-build115.apk`：推荐，单 APK 内置 Agent，不依赖 AVF Linux。
- `AirSIM-Android-AVF-0.9.8.10-build115.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent Debian 更新。
- `AirSIM-iOS-0.9.8-build139-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build139-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用既有 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。Debug／第三方重签包不能直接用正式证书包覆盖。公开 IPA 不包含 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight。
