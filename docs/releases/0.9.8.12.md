# AirSIM Apps v0.9.8.12 — 短信兜底通知、可复制云端自检与日志分享修复

日期：2026-10-25（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.12 (117)`，iOS／Watch／Live Activity `0.9.8 (141)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM、双 SIM、锁屏或长时后台场景均已验收。

## 更新内容

- **短信通知兜底**：云端模式下不再因为“存在 alert token”就直接跳过本地通知。Push 已到则本地不重复；Push 未到或 APNs 异常时，等待 2 秒后使用同一 `agentID + delivery_id` 账本发本地通知。本地模式的短信通知不受影响。
- **Verbose 日志分享修复**：移除容易在 iOS 18 卡死的 SwiftUI `fileExporter`／`FileDocument` 路径，改为生成临时 TXT 后使用系统 `UIActivityViewController` 分享；支持 AirDrop、存储到“文件”等，关闭后清理临时文件。
- **云端自检拆成 6 步**：
  1. 本机配置：云端开关、设备 ID、APNs 环境、PushKit/通知 token、Relay host
  2. Relay 身份
  3. 设备注册
  4. Agent 记录：登记数量、设备名、standalone/AVF、在线状态、命令路由版本、active agent
  5. Agent 心跳：90 秒内是否有有效心跳、版本、蜂窝状态
  6. 命令路由：Agent 是否声明 `command_routing_version`，缺失时明确提示接听/挂断无法定向
- **自检结果可复制**：步骤标题和详情支持选中复制，并新增“复制自检结果”按钮；复制内容只含状态、设备提示、Agent 元数据和错误，不含 token、secret、号码或短信正文。
- **Relay／云端 Verbose**：保留 `Relay / 云端` 筛选，包含 `cloud-call-control`、`cloud-call-audio`、`cloud-media-health` 等事件。
- **手动配对**：保留上一版“手动配对总是绑定新 Agent + 首次健康检查短重试”。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.12-build117.apk`：推荐，单 APK 内置 Agent，不依赖 AVF Linux。
- `AirSIM-Android-AVF-0.9.8.12-build117.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent Debian 更新。
- `AirSIM-iOS-0.9.8-build141-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build141-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用既有 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不包含 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight。

## 验证与已知限制

- Android Standalone JVM 测试通过；Android 版本仅版本号变化，业务代码与 0.9.8.11 相同。
- iOS 全量 310 项测试：仅既有 2 项 `OtherDeviceCallReminderTests` 基线失败；新增自检复制回归通过。
- Android APK 使用 AirSIM Release 证书；iOS 未签名 IPA 包含 Watch 包结构。
- 短信兜底不保证 APNs 推送一定成功；它解决“Push 未到导致本地通知被完全吞掉”的问题。
- 云端来电仍依赖 Android Agent 云端注册、90 秒心跳和 `command_routing_version`；本地模式与云端模式是两条独立通路。
- 当前未完成所有 OEM 双向音频、双 SIM/eSIM、真实换卡、弱网/锁屏长时后台和 APNs 真机全矩阵验收。
- 2026-10-25 06:15（Asia/Shanghai）通过 `xcodebuild -exportArchive`（`destination=upload`）上传 App Store Connect，回执为 `Upload succeeded`、`Uploaded package is processing`；上传成功不代表 Apple 处理完成、外测审核或测试者可更新。
- 公开 IPA 为未签名包；TestFlight 上传、Apple 处理、外测审核与测试者可更新分别核实。
