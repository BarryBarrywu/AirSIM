# AirSIM AVF Agent 0.4.7-1

日期：2026-10-24（Asia/Shanghai）。独立 Linux AVF Agent 发布，Debian 包版本 `0.4.7-1`，架构 `arm64`。Android/iOS 应用发布为 [v0.9.8.10](0.9.8.10.md)。

## 更新内容

- **通话身份归并**：通话记录和云端事件携带 `android_id`；`/api/health` 增加 `canonical_call_ids`，让新版 AVF Bridge/iOS 能按 Android 原始 Telecom 身份归并 VoWLAN／VoBLE 通话，不按号码或时间猜测。
- **拨号/DMTF 身份校验**：拨号请求接受可选 `operation_id`；DTMF 增加可选 `call_id`，非当前通话时拒绝执行，避免旧通话或错误归属的命令落到新通话。
- **云端命令路由**：命令连接按注册配置隔离，增加命令 epoch、目标 `agent_id` 校验、重连退避和 `Retry-After` 处理；配置变化后旧连接/旧命令不会覆盖新会话。
- **推送与心跳**：PushKit/命令事件携带 `agent_id`，心跳增加 `command_routing_version`，便于 Relay 定向到正确的 Android Agent。
- **命令生命周期**：增加云端命令重试、完成回执、WebSocket 关闭分类和并发/过期测试，减少 Relay 重连或切换设备时的重复执行。

## 升级与兼容

- 已安装 `0.4.6-1` 且 installerd 正常的设备，可通过 AirSIM Android App 更新到 `0.4.7-1`；包名、架构和 Ed25519 发布公钥不变，不需要重新配对或执行密钥迁移。
- 仍停留在 `0.4.4-1` 的设备必须先按 [AVF 安装指南](../AVF_INSTALL_GUIDE.md)执行一次性 `rotate-avf-key.sh`，不能直接使用新版包。
- 首次安装命令固定到 [v0.4.7](https://github.com/kai-wu-cortex/AirSIM/releases/tag/v0.4.7)；不要删除 `current.deb` 或清空 AVF 数据来绕过安装失败。
