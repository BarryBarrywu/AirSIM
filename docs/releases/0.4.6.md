# AirSIM AVF Agent 0.4.6-1

本版将 Android Standalone 与 iPhone 多 Agent/本地模式改造所需的 Agent 协议同步到 AVF Linux，并加强通话控制与 Relay 恢复能力。

## 主要变化

- 配对注册新增 Android Agent 身份、类型、设备名称、厂商、型号和手机号码；心跳同步这些字段，支持 iPhone 在多个 Android Agent 间显示和选择路由。
- 支持本地模式注册。本地模式不要求 Relay、PushKit、CallKit 或云端设备参数，并强制关闭云端命令与推送路径。
- VoWLAN 接听、拒接和挂断支持携带 `call_id`；Agent 会拒绝过期或不匹配的通话 ID，避免延迟通知控制下一通电话。
- 云端命令 WebSocket 增加分级退避重连，短时断网或 VPN 切换后不再高频重连 Relay。
- 云端挂断增加通话结束确认和重试，降低 iPhone 已挂断而 Android 仍响铃或仍处于通话中的概率。
- Debian 构建兼容 GNU tar 与 BSD tar；首次安装脚本继续支持已有安装的无损恢复和重新配对。

## 安装与更新

首次安装或恢复服务：

```sh
bash -o pipefail -c 'curl -fsSL --connect-timeout 10 --max-time 90 --retry 2 --proto =https --proto-redir =https --tlsv1.2 https://github.com/kai-wu-cortex/AirSIM/releases/download/v0.4.6/install-avf.sh | sudo sh'
```

已安装 `0.4.5-1` 且 installerd 正常的设备，可直接在 Android AirSIM AVF 管理页更新到 `0.4.6-1`。仍停留在 `0.4.4-1` 的设备必须先按 [AVF 安装指南](../AVF_INSTALL_GUIDE.md)执行一次性信任根迁移，不能直接使用 App 内更新。

## 验收

1. `dpkg-query -W airsim-avf-agent` 显示 `0.4.6-1`。
2. `systemctl is-active airsim-agent airsim-installerd` 均返回 `active`。
3. `http://<AVF-IP>:8575/api/health` 返回 `product=airsim`、`version=0.4.6`。
4. 在 Android App 中重新配对后，验证本地模式、Relay 云端模式、拨号、接听、拒接、挂断、短信和双向 PCM 音频。
