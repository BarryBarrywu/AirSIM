# AirSIM Apps v0.9.8.20 — 后台接听、VoWLAN 恢复与号码显示

日期：2026-10-31（Asia/Shanghai）。基于 VoBLE 分支，包含 PR #18 与后续回归修正。
Android Standalone／AVF Bridge `0.9.8.20 (125)`；iPhone／Watch／Live Activity `0.9.8 (152)`。

## 更新内容

- 接听后的 PCM 音频启动与前后台轮询任务解耦；取消后的新请求等待旧任务清理再串行交接，避免启动被吞掉或双重启动。
- 未接听且未锁定传输的来电允许 VoWLAN 恢复认证；已接通／已锁定通话不切换链路。
- 取消 HTTP 请求时及时关闭底层连接；多台设备独立并发验证，回前台重新取得即时状态快照，减少等待旧长轮询。
- iPhone 与 Watch 的无区号号码按原样交给 CallKit 展示，不猜测接收设备的国家；明确的 `+86`、真实 `+1` 等国际区号保留，不修改拨号目标或历史记录。
- 不同网关的 Push 注册独立排队；Android 放行认证后的来电推送 POST 路径。Worker 来电生命周期按设备、Agent、通话身份隔离，避免不同网关互相抑制。

## 安装与分发

- Android APK 沿用原 AirSIM Release 证书；同包名同签名可覆盖升级。Debug／其他签名包不能直接覆盖，不要为升级而卸载清数据。
- GitHub 提供 full／sideload **unsigned IPA**，需要使用自己的 Apple 开发者身份重签；不是可直接安装或上传 TestFlight 的包。
- TestFlight 使用独立的 production APNs 归档上传。上传、Apple 处理、外测审核、测试者可更新分别核实。
- 本轮不发布 Linux Agent、不部署 Worker。既有维护者服务端修复已在此前部署；自部署者需自行更新 Worker，不会由 APK／IPA 更新服务器。
- 本地安装 build 150／151 为 development APNs 测试包，不是本次 production 分发包 152。

## 验证与限制

- 前一轮后台恢复修正已通过 378 项 XCTest。本次新增 9 项号码展示／CallKit 入口测试已编译，但模拟器测试启动停滞；重启及独立模拟器重试均未获得执行结果，已中断卡住的测试。**不能声称本次 iOS 完整回归通过**。
- Android 核心与 Standalone 完整测试通过，包括云端通话、纯本地模式、Relay 出口及上传控制；版本断言同步到 125。Worker 67 项测试通过，语法检查通过；unsigned 打包脚本测试通过。
- 本地 build 151 已覆盖安装 iPhone Air，联系人、短信、通话记录保留；这不等于 production 推送或号码显示已经真机验收。
- 尚无美区故障设备截图／原始 payload，不能断言 Apple ID 是直接原因，也不修复上游已经写错的 `+1`。无区号号码改用通用句柄后，系统通讯录关联与系统最近通话回拨仍需真机验证。
- 锁屏接听、强制退出后的行为、双向声音、Watch、Tailscale／DHCP 换址仍需真机复测；不承诺强制退出后仍可靠唤醒。
- 纯本地模式的跨端认证协商与零 Relay 流量仍需端到端验收，不据本次发布宣称完成。

TestFlight 152 待上传，上传成功后另行记录 Apple 回执。旧签名配置中的 build 149 覆盖曾在本地版本核验时被拦截，该候选未上传；改用显式 build 152 的独立配置重新归档。
