# AirSIM Apps v0.9.8.8 — 时钟校正、双卡短信/卡槽、Root 通道、私有网段与端口、VoBLE 音频修复

日期：2026-10-20（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.8 (102)`，iOS／Watch／Live Activity `0.9.8 (113)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM 双向音频、双 SIM、Root 或长时后台场景均已验收。

## 更新内容

- 配对时钟校正：`/pair/v1/info` 返回 `server_time`，iOS 手动配对保存 clock offset，VoWLAN HMAC 时间戳使用校正值；旧 Android 无该字段时 offset 为 0。
- 双卡能力：`sim_slots` 增加 slot/subId/carrier/eSIM/默认语音/默认短信元数据；iPhone 短信使用当前所选卡槽（`sim_account`）；Android 通话事件/status 增加实际 `slot_index`，iPhone 通话界面显示 SIM 卡槽；Android `SubscriptionManager` 变化通过 VoWLAN `/api/events` 推送，iOS 实时刷新 SIM 菜单。
- KernelSU Root 通道：新增全局 root 特权传输，复用 PCM、静音、AudioManager 快照、拨号角色和短信；设置页可选择自动（Root 优先）/仅 Shizuku/仅 Root，并支持 Root 授权/重试。Root 不可用时回退 Shizuku。
- 私有网络与端口：可追加 CIDR（如 `30.0.0.0/8`）；可设置配对端口、VoWLAN 控制端口与 PCM 首选端口，被占用时自动回退并通告实际端口。iOS 设置页同步支持私有网段。
- VoBLE 本机静音修复：三星不再把通话音量压到 0（会同时压掉转发给 iPhone 的 `VOICE_DOWNLINK` 采集），改用最低非零音量；挂断恢复原音量/静音位。VoBLE/VoWLAN 均走采集安全策略。
- 灵动岛只保留 Agent 状态：按用户要求删除来电/通话中/保持、计时和接听/挂断按钮；云端、VoBLE、VoWLAN 通话全部交给 CallKit。旧通话态活动渲染时归一化为待机，挂断/远端挂断只刷新待机，后台仍显示 Agent 状态。
- VoWLAN 文案：只有 `100.64/10` 才显示“VPN 直连”，普通私网显示“同一局域网”（路由行为不变）。
- 其它：`StandaloneLongPoll` 缺省 `after=0`；Root/Shizuku 短信失败回退旧路径；Live Activity 动作改为 App 内统一路径。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.8-build102-Android10-13.apk`：推荐，单 APK 内置 Agent，不依赖 AVF Linux。
- `AirSIM-Android-AVF-0.9.8.8-build102-Android10-13.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent Debian 更新。
- `AirSIM-iOS-0.9.8-build113-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build113-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用既有 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。Debug／第三方重签包不能直接用正式证书包覆盖。公开 IPA 不包含 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight。
