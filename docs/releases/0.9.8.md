# AirSIM Apps v0.9.8 — 本地双通道、设备归属与云端挂断修复

日期：2026-10-18（Asia/Shanghai）。从 `VoBLE` 分支发布；Android Standalone／AVF Bridge、iOS／Watch／Live Activity 均为 `0.9.8 (92)`。推荐 Android 10–13 用户升级，优先安装 Standalone；保留此前旧系统 Java API、短信工厂和蓝牙认证兼容修复。支持更高 Android 版本不代表全机型音频已验收。

## 下载与升级

- `AirSIM-Android-Standalone-0.9.8-Android10-13.apk`：正式签名、推荐入口，内置 Agent，不需要 AVF Linux。
- `AirSIM-Android-AVF-0.9.8-Android10-13.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent 更新。
- `AirSIM-iOS-0.9.8-build92-unsigned.ipa`：包含 Watch 与 Live Activity，须完整重签。

- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 沿用既有发布证书，可覆盖同包名、同证书正式版并保留数据；不要先卸载。不能覆盖不同证书的 Debug／第三方重签包。公开 IPA 没有 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight；维护者另用 Xcode 上传 production 推送环境构建。上传、处理、外测审核与测试者可更新是不同状态，以实际回执为准。

## 本版内容

- 新增本地双通道：同一安卓同时连接 VoWLAN 与 VoBLE，拨号前优先 Wi-Fi、其次蓝牙；只启用一路音频，通话中不自动换路，不依赖 Relay。
- 多安卓设备目录与通话归属：默认拨出设备可选，来电按来源设备操作；通话、CallKit、Watch、实时活动和媒体均绑定同一设备／通话身份，避免迟到回执控制另一通电话。
- VoWLAN 健康证明、设备级密钥和带身份的拨号回执；保留旧客户端协议，不能以 HTTP 200、号码或名称代替身份校验。
- 修复短信会话点击与多选删除冲突；配对发现隔离旧扫描回调，并修复 Bonjour IPv6 配对被手动 IPv4 来源规则误拒。
- VoBLE 首次拨号读取认证后的 Android 通话序号，防止 `stale_generation`；取消预检不会迟到拨出，重复或过期序号不能产生第二次蜂窝拨号。
- 修复蓝牙通话切换模式后挂断的清理顺序：界面立即结束，但认证控制链路保留到挂断命令完成，避免先断开蓝牙而遗留安卓通话。
- 短信历史按经过认证的来源设备隔离身份、去重和删除；相同短信来自不同安卓时不再合并，回执仍使用原始 ID 发回实际来源。无法确认来源的旧记录保留，不猜测归属。
- 修正等待音覆盖 CallKit 双向音频会话、音频图格式与采集 Tap 启动路径；不会关闭认证或用无限重试掩盖硬件问题。
- 云端挂断同时识别 Android Telecom 的 `android_confirmed` 与旧基带的 `modem_confirmed`；仍要求命令完成且 `ended=true`，不将已送达当作挂断成功。
- 设置顶部增加「仅本地模式」，直接联动现有连接模式，不另存独立开关；配对页「仅本次配对不写入云端」仍只影响本次配置包。关闭全局本地模式不会擅自上传先前明确选择的本地配对凭据。
- Verbose 移除 AT／USB 筛选，增加 VoWLAN／VoBLE 专项；异常记录阶段、源码位置和底层错误，增加音频引擎／采集／收发诊断，支持本机 UTF-8 TXT 导出。日志不应包含 PCM、密钥或 Push token，分享前仍请检查隐私。

## 兼容与验收边界

本轮不部署生产 Relay、不新增 workflow、不合并 main，不发布新的 Linux AVF Agent 二进制。AVF 源码已增加 `android_id`／`canonical_call_ids` 协议，但公开 Debian 仍为 v0.4.6；旧 AVF 不具备能力时，新设备归属 VoWLAN 拨号会明确拒绝，不能把仅升级 Bridge 当作完整双通道支持。新安装推荐 Standalone。

三星 Flip7 与 iPhone Air 已做候选包保留数据安装；日志确认蓝牙拨号、音频引擎／采集启动、媒体传输与挂断回执。用户暂不测第二台安卓，因此多安卓同时待机／来电仍未真机验收。最近的音频修改、云端挂断回执修复与顶部开关尚待用户最终复验，不能把自动化测试或字节计数写成双向听感通过。

已观察到一次重新配对后的 VoWLAN 鉴权失败；云端重新配对已恢复注册及心跳，但该本地场景仍需复验。各 OEM、真实 Tailscale、长时锁屏、弱网及 Watch 后台响铃仍须分别验证。最低通话音量不等于完全静音；Android 默认电话角色、Shizuku 和厂商蜂窝 PCM 支持仍是前提。

发布前 iOS 全量回归通过 267 项 XCTest（0 失败）；Android 全套、Go（含 race）／Relay 测试与 IPA 打包正反例均通过。发布产物结构／签名检查和 Apple 上传回执在完成后另行记录。这些结果不是 build 92 的真机通话验收。
