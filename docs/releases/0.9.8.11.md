# AirSIM Apps v0.9.8.11 — 云端接听、注册自愈、灵动岛分页与手动配对修复

日期：2026-10-24（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.11 (116)`，iOS／Watch／Live Activity `0.9.8 (140)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM、双 SIM、锁屏或长时后台场景均已验收。

## 更新内容

- **云端接听修复**：CallKit 接听后，后台静音引擎不再 deactivate 共享 `AVAudioSession`，也不会在 CallKit 活动时重新抢占音频会话；解决 iPhone 接听后约 2 秒自动挂断、Android 仍保持的问题。
- **App 内接听页状态**：云端 session 已 `answered` 时，App 内页面直接显示通话中/挂断，不再把 `connecting` 误判为 incoming 而要求第二次接听。
- **Android 云端注册自愈**：旧/直接配对记录缺少 `android_agent_id` 时，读取 registration 自动补齐本机身份；修复 `standalone_agent_cycle_failed: No value for android_agent_id` 导致 Relay 注册、命令、来电 Push 全部失效的问题。
- **Verbose Relay/云端筛选**：`Relay / 云端` 现在包含 `cloud-call-control`、`cloud-call-audio`、`cloud-media-health`、`cloud*` 与 Relay 事件；通话筛选也补入云端音频/健康事件。
- **灵动岛 5 台分页**：待机、锁屏和展开列表每页最多显示 5 台 Android Agent；超过 5 台时右上角按钮翻页，并显示“第 x/y 页 · 共 n 台”。
- **灵动岛置顶/排序**：设置 → 灵动岛与实时活动 → 灵动岛设备排序，支持图钉置顶和上移/下移；置顶设备固定在前，排序持久化。
- **手动配对修复**：手动配对成功后总是绑定新 Agent，避免旧绑定导致新 Tailscale 路由不被探测；首次健康检查失败后增加一次短重试。
- **Tailscale 提示**：Android 同时只能有一个 `VpnService`；Clash/WireGuard 等占用 VPN 时 Tailscale 不会获得 100.x 地址，需先关闭冲突 VPN。
- **独立 AVF Agent**：Linux AVF Agent `v0.4.7-1` 已单独发布，包含 canonical call IDs、命令路由/重试与 DTMF 身份校验；本次应用 Release 不再重复打包 Debian。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.11-build116.apk`：推荐，单 APK 内置 Agent，不依赖 AVF Linux。
- `AirSIM-Android-AVF-0.9.8.11-build116.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent Debian 更新。
- `AirSIM-iOS-0.9.8-build140-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build140-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用既有 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。公开 IPA 不包含 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight。
