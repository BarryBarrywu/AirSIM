# AirSIM Apps v0.9.8.9 — VoBLE 稳定性、全屏来电、SIM 通知与短信辅助

日期：2026-10-22（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.9 (114)`，iOS／Watch／Live Activity `0.9.8 (136)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM 双向音频、双 SIM、Root 或长时后台场景均已验收。

## 更新内容

- **VoBLE 控制链路修复**：Android 控制消息分片上限修正为 512 字节，解决 `device_info` 响应超过 ATT 上限导致 `GENERATION_SYNC` 超时、拨号命令无法下发的问题；控制响应增加字节数、入队和 indication 状态日志。
- **VoBLE 保活与重连**：切换连接模式或 Android Agent 时保留 BLE 链路；选中会话断线后按 1/2/4/8/16 秒退避自动重连，连上后清零重试预算。修复单 Agent 切换时旧会话未停止的问题。
- **小米短信辅助**：新增无障碍辅助操控，仅在 AirSIM 发起系统短信时点击 MIUI 的“发送/允许”确认；新增 SMS 调试过滤、结果码映射（16 = 调制解调器错误）、默认 SIM/短信 App 诊断，以及非默认短信 App 的 MIUI 限制提示。
- **本地模式短信**：无 VoWLAN HTTP 时通过已认证 VoBLE 控制通道发送短信，命令超时提高到 60 秒。
- **小米回信显示**：可选通知读取转发，只读取 `com.android.mms` 新短信通知，过滤“短信正在运行 / 点按即可了解详情或停止应用”等状态通知，转发到 iPhone；解决非默认短信 App 无法读取 MIUI inbox 的问题。
- **全屏来电**：不论“远端静默”还是“本机显示”，Android 呼入都使用全屏来电页和最高优先级来电通知，显示号码、接听、拒接、挂断；模式选择改为点击即保存，不再依赖单独的保存按钮。
- **通知栏**：状态通知增加“切换默认卡”，来电通知保留接听/拒接，通话中提供挂断；服务通知加入统一 `airsim_services` 组，减少通知栏视觉数量。
- **灵动岛**：待机态增加 Android Agent 切换按钮；优化锁屏 Agent 行和灵动岛右上角布局，避免连接标签/按钮被压成竖排。
- **VoWLAN 恢复**：AppModel 接管 CallKit 后释放冷启动 VoWLAN 浏览器；相同 Wi‑Fi 状态不再反复重建 Bonjour，减少 `BROWSER_RESTARTED`/恢复风暴。
- **iOS 后台/接听**：补充本地双通道接听、Android 已接听云端来电时 iPhone 停止本地响铃、VoWLAN 前台恢复不打断通话等策略。
- **诊断**：Android SMS/VoBLE/来电日志、iPhone SMS Verbose 事件、Live Activity Agent 切换与冷启动恢复日志。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.8.9-build114.apk`：推荐，单 APK 内置 Agent，不依赖 AVF Linux。
- `AirSIM-Android-AVF-0.9.8.9-build114.apk`：旧 AVF 部署的 Android Bridge，不是 Linux Agent Debian 更新。
- `AirSIM-iOS-0.9.8-build136-unsigned.ipa`：包含 Watch 与 Live Activity，需完整重签。
- `AirSIM-iOS-0.9.8-build136-sideload-unsigned.ipa`：不含 Watch、保留 Live Activity，仍须侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

正式 APK 使用既有 AirSIM Release 证书，可覆盖同包名、同签名安装；不要先卸载或清除配对数据。Debug／第三方重签包不能直接用正式证书包覆盖。公开 IPA 不包含 Apple 签名或设备描述文件，不能直接安装或上传 TestFlight。

## 验证与已知限制

- Android `phone-control-app` JVM 测试全量通过，包括短信、通知动作、音频策略、VoBLE 和 Direct PCM 场景。
- iOS 全量 298 项 XCTest 通过，0 失败；Android 测试与 Relay `npm test`/`npm run check` 通过。
- 小米默认短信角色不可授予：该 ROM 要求 `SEND_RESPOND_VIA_MESSAGE`（signature|privileged），第三方 App 无法注册为默认短信应用；收发依赖辅助操控和通知读取回退，不是默认短信角色方案。
- 直接呼 Android 号码已提供全屏来电和接听/拒接；直接呼 iPhone 原生号码不会产生 Android Telecom 事件，跨端镜像来电仍需另行实现。
- 双 SIM/eSIM、真实 KernelSU 小米、受限端口/特殊网段、VoBLE 双向通话、锁屏全屏通知权限和通知读取权限仍需真机复验。
- 公开 IPA 为未签名包；TestFlight 上传、Apple 处理、外测审核与测试者可更新分别核实。
- 2026-10-22 10:25（Asia/Shanghai）通过 `xcodebuild -exportArchive`（`destination=upload`）上传 App Store Connect，回执为 `Upload succeeded`、`Uploaded package is processing`；导出包校验 `aps-environment=production`、`get-task-allow=false`、`CFBundleVersion=136`。上传成功不代表 Apple 处理完成、外测审核或测试者可更新。
