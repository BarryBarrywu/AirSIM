# AirSIM Apps v0.9.8.2 — 通话路径、双 SIM 选择、灵动岛与 PCM 探活修复

日期：2026-10-19（Asia/Shanghai）。Android Standalone／AVF Bridge `0.9.8.2 (96)`，iOS／Watch／Live Activity `0.9.8 (96)`，从 `VoBLE` 分支发布。推荐 Android 10–13 用户升级 Standalone；不能把推荐安装理解为所有 OEM 双向音频、双 SIM 或长时后台场景均已验收。

## 更新内容

- 多设备通话路径审查修复：只把已验证的本地 peer 计入拨号目标；绑定设备离线时不再把另一台显示为当前设备；云端通话占用主展示时，本地来电保留为“其他设备”提醒；接听失败释放媒体／registry active 并恢复响铃页；直接拨号失败清理 pending；BLE `start_media` 仅对 `disconnected`／`notReady` 做一次重试；云端来电仅在 `startsVoWLAN` 时启动本地浏览。
- 跨传输边界：本地 ringing/active 或云端通话时拒绝新拨号；云端通话进行中禁用“其他设备接听”；本地通话展示期间不接收云端 PushKit 主展示。
- 多 SIM 卡槽选择：配对安卓上报多于一个 call-capable SIM/PhoneAccount 时，iPhone 拨号页当前设备卡显示 `simcard.2` 小按钮；展开可选择**本次拨号**使用的卡槽，菜单显示卡槽标签与号码，选择按 agent 记忆，不修改安卓全局默认通话卡。Standalone 的 BLE 与 VoWLAN 拨号支持；AVF Go Agent 与 Cloud Relay 命令尚未透传该字段，会回退默认卡。
- 灵动岛：离线判断纳入当前 Agent 的 VoWLAN/VoBLE 在线状态，本地双通道下 USB 断开但 BLE/Wi-Fi 仍在线时不再误报离线；离线文案改为 **“Agent 离线”**，待机/来电/兜底同步改为 Agent 文案。
- PCM 探活与握手：`PhoneAudioBridge` 先校验 `AIRSIMPCM1` hello，再创建 AudioRecord/AudioTrack；`VoWLANGatewayService.portOpen()` 的裸 TCP 探活以 `ProbeClosed` 静默关闭，不初始化音频、不记录 `handshake_failed`、不短暂占用音频端点。空闲 `pcm_health` 日志改为状态变化／30 秒心跳；通话中保持每秒并带 `in_call`。
- 保留此前 BLE 广播重启恢复、SAS 状态刷新、云端后台待机、应用更新说明／检测等修复。
