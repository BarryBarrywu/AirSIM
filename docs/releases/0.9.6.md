# AirSIM Apps v0.9.6

本版将 Android Standalone 的本地与云端编排补齐，并集中改善真实来电、短信、网络切换和 iPhone 实时活动的可靠性。AVF Agent 仍为独立的 `v0.4.6`；本次 Apps Release 新增 AVF Bridge APK，方便继续使用 Linux Agent 的设备覆盖升级。

## 主要变化

- Android Standalone 支持不依赖 Relay、PushKit 和 CallKit 的本地模式；启用本地模式时云端开关不可操作，并保留 VoWLAN 控制与 PCM 通话音频。
- Android 增加可选 `READ_SMS` 扫描兜底、去重游标与近期投递记录，降低厂商系统漏发短信广播时的漏收概率。
- Android 来电提供锁屏全屏页与通知接听、拒接、挂断操作，并加强 Telecom 通话目标选择、静音重试、PCM 监听恢复和进程守护。
- iPhone 拨号页集中显示当前 Android、手机号、Standalone/AVF、VoWLAN 与云端状态，并支持多个已配对 Agent 的列表和自动回退。
- iPhone 本地模式不再因 Relay 注册、PushKit token 或云端状态失败而阻塞配对；云端状态只在打开 App、拨号前和实时活动出现前查询。
- iPhone 在 VPN 关闭或网络路径变化后主动恢复 VoWLAN；实时活动增加显示开关，重新设计紧凑/展开布局与渐进式 Liquid Glass 背景。
- 修复 Android 已结束来电后 iOS 收到延迟 CallKit 挂断回调，错误重试后弹出“本地链路和云端语音都不可达”的问题。
- Relay 将高频心跳和设备状态迁入 Durable Objects，并增加云端控制幂等、超时救援、多 Agent 路由与配额降级路径。

## 安装与验证

AVF Bridge 包名为 `com.airsim.phonecontrol`；Standalone 包名为 `com.airsim.phonecontrol.standalone`。两者使用同一正式 Android 发布证书，但不能相互覆盖。公开 IPA 不含 Apple 签名或 provisioning profile，不能直接安装或提交 TestFlight；正式维护者构建使用 `com.eric3u.airsim`、production APNs 和 App Store Connect 分发签名。

发布前执行 Android AVF/Standalone、AVF Agent、Relay 和 iOS 测试，并验证两份 APK 的版本、release 签名与 `debuggable=false`，以及 iOS Release archive 的主 App、Watch App 和 Live Activity Extension 签名。实体三星与 iPhone Air 已用于本地来电、挂断、VoWLAN 与实时活动回归；不同运营商和机型仍需单独验收。
