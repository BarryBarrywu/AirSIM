# AirSIM Apps v0.9.7.2 — 连接恢复、VoBLE 与音频诊断

日期：2026-10-16（Asia/Shanghai）。从 `VoBLE` 分支发布，Android Standalone／AVF Bridge 为 `0.9.7.2 (91)`，iOS／Watch／Live Activity 为 `0.9.7 (91)`。推荐 Android 10–13 用户升级，保留此前旧系统启动、日志读取与蓝牙配对兼容修复；新安装优先 Standalone。Linux AVF Agent 二进制仍为 `v0.4.6`，本次不发布 Debian、不部署生产 Relay、不新增 workflow、不合并 main。

## 下载与安装

- `AirSIM-Android-Standalone-0.9.7.2-Android10-13.apk`：正式签名，推荐。
- `AirSIM-Android-AVF-0.9.7.2-Android10-13.apk`：旧 AVF 部署的 Android 控制端，不是 Linux Agent 更新。
- `AirSIM-iOS-0.9.7-build91-unsigned.ipa`：包含 Watch 与 Live Activity，须自行完整重签。
- `AirSIM-iOS-0.9.7-build91-sideload-unsigned.ipa`：不含 Watch，保留 Live Activity，供不支持嵌套 Watch App 的侧载工具重签。
- `SHA256SUMS.txt`、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md`。

两份 APK 沿用原正式证书，`minSdk=29`、`targetSdk=35`，可覆盖同包名、同证书正式版并保留数据。不要先卸载；Debug 或第三方重签包签名不同，不能直接覆盖。支持 Android 10–13 不代表排除高版本，也不代表所有 OEM 音频路径均通过实测。

公开 IPA 无 Apple 签名或设备描述文件，不能直接安装或直接上传 TestFlight；侧载工具仍须使用自己的 Team、Bundle ID 及相应能力重签。维护者另用 Xcode 上传正式 production 推送环境构建。上传、Apple 处理、外测审核和测试者可更新是不同状态，后续以实际回执为准。

## 本版内容

- iOS 联系人采用系统完整姓名格式，包含 middle／family name；iOS 与 Android「关于」显示实际版本与仓库链接。
- VoWLAN 配对支持手动 IPv4＋配对端口，可绕过 Bonjour 发现；保留六位码加密认证，支持局域网及 Tailscale 地址，不对外开放 AVF／Shell 内部端口。
- iOS 短信支持单条、会话和多选删除，仅删除本机 AirSIM 记录，避免旧同步重新加入，不删除 Android 系统短信。
- 同网恢复重新发现、认证 VoWLAN；自动模式空闲时按 VoWLAN → VoBLE → 云端选择，固定模式与通话中的链路不被改变，不增加 Relay 定时状态查询。
- VoBLE 扫描与音频工作移出主线程、合并状态更新，改善切换模式时卡顿；加强断链清理、重连及代际隔离。
- 蓝牙挂断后阻止迟到的非终态恢复通话与灵动岛计时，处理 iOS 临时 ID 到 Android 权威 ID 的切换。
- Android 蓝牙特征发布及认证兼容性、X25519 密钥生成后端适配；配对前继续要求完整特征与认证，不降低安全校验。
- 音频 Watchdog 只针对已确认的唯一远程通话和就绪 PCM，有限次修复，可导出脱敏 VERBOSE TXT；不修改麦克风或 PCM 增益。
- 三星改为接通后设置系统支持的最低通话音量，挂断／链路丢失后恢复原值；最低档不等于静音。修复 `IdentityHashMap.containsValue` 将解码通话 ID 按对象引用比较，导致 VoBLE／云端未触发音量策略的问题。
- Relay 多安卓命令固定目标、通话归属与 HTTP／WSS 退避源码一并提交；生产 `/healthz` 已只读确认 `agent_command_routing=1`。第三方部署须先升级兼容 Relay，再升级 Android／Apple；新客户端不会静默回退到无法隔离目标的旧协议。

## 验证与已知边界

候选 iOS 88 用户反馈切换 VoBLE 不再卡顿；候选 Android 90 真机 VoBLE 通话未降低音量，日志显示双向 PCM 已工作但音量策略未触发。91 增加独立字符串 ID 的失败复现与回归后修正，已覆盖安装三星并启动，**最低档听感与 iPhone 双向语音仍待用户复验**，不声称三星已完全静音。

真实 Tailscale 两端、所有 OEM／Android 版本、Apple Watch 后台响铃停止、长时锁屏与弱网仍需分别验收。iOS 强制退出后的 BLE 后台唤醒不保证；Android Shizuku、默认电话角色与厂商蜂窝 PCM 支持仍是前提。实时活动、后台连接和降音量的自动化测试不能替代真机声学验证。

发布前重新执行 Android 全套、iOS 测试、IPA 打包回归、Relay／Go 测试与正式产物签名检查；执行结果另行记录。发布不包含用户日志、号码、配对材料、Apple 身份或任何签名私钥。
